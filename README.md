## Project Overview
This repository organises all working documents for the research project *Using Generative AI Tools - Boon or Bane*. It stores literature resources, quantitative and qualitative research materials, manuscript drafts, reports and supplementary media files. Sensitive participant‑identifiable data will **not** be uploaded to this GitHub repository for privacy protection.

## Repository Folder Structure
- **01_literature_review/**: Academic journal articles, conference papers, books and newspaper resources for literature review
- **02_quantitative_analysis/**
  - `survey_data/raw`: Original unmodified survey dataset
  - `survey_data/cleaned`: Processed and cleaned survey data
  - `survey_questions/`: Survey questionnaire documents
  - `scripts/`: Python analysis scripts
  - `excel/`: Excel data files
  - `reports/`: Quantitative survey analysis reports
- **03_qualitative_analysis/**
  - `transcripts/`: Interview transcript files
  - `protocols/`: Interview protocol documents
  - `consent_forms_RESTRICTED/`: Participant consent forms (restricted sensitive data, not shared publicly)
  - `reports/`: Qualitative insight and analysis reports
  - `visualisations/`: Data visualisation outputs
- **04_drafts_and_reports/**: Draft research proposals, conference papers and final research reports
- **05_additional_materials/**: Information sheets, photos and other supplementary media files

## File Navigation Instructions
1. Navigate to numbered top‑level folders to locate materials by research type.
2. Keep raw source data separate from cleaned or modified derived data.
3. Analysis scripts are stored independently from dataset files.
4. Distinguish working drafts from completed final reports.
5. Placeholder.txt files exist to preserve empty folder structure for Git tracking.

## File Naming Convention
Consistent file naming rule: `YYYYMMDD_description_version.file‑extension`
Example: `20260914_survey_cleaned_dataset_v02.csv`
Avoid ambiguous names such as `final.docx`, `final_v2.docx`.

## Collaboration & Contribution Guidelines
1. Always pull the latest changes from `main` branch before starting new edits.
2. Create a new dedicated branch before modifying shared project files.
3. Write descriptive, meaningful commit messages for every change.
4. Submit pull requests for review before merging work into the main branch.
5. **Do NOT upload participant‑identifiable sensitive data to this repository.**
6. Private sensitive materials including signed consent forms and identifiable interview records must be stored in password‑protected access‑controlled storage outside GitHub.
